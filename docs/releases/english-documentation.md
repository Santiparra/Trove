# English documentation and a Spanish quick guide

This documentation update is included in [Light novels, enriched and organized](novel-tracking-and-ranobedb.md); it is not a separate published release.

Trove's public documentation is now maintained in English, making the project easier to explore and contribute to while keeping a concise starting point for Spanish-speaking users.

- The README and usage, development, architecture, security, backup, testing, and publication guides are available in English.
- A short Spanish guide covers downloading and running Trove, starting a development environment, and everyday library management.
- The Spanish guide is reviewed when preparing release PRs, while English documentation is maintained during everyday development.
- Previously published release notes are preserved in their original language. New release notes are written in English.

The application interface remains in Spanish. This documentation update does not change library data, provider behavior, or backup formats.
