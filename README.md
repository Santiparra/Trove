# Trove

Biblioteca y bitácora personal multimedia, local e independiente de los proveedores externos. Nombre provisional.

## Estado

Proyecto en planificación. No hay aplicación implementada ni stack aprobado. Los documentos distinguen requisitos confirmados, propuestas y preguntas abiertas.

Uso previsto: una persona, en una sola PC, sin acceso remoto ni móvil y sin cuenta propia de Trove.
