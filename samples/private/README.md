# Exportaciones personales (solo uso local)

Colocar aquí los archivos originales exportados desde The StoryGraph, MyAnimeList, Trakt e IMDb para analizar sus formatos. Por ejemplo: `storygraph.csv`, `myanimelist-anime.xml`, o el nombre y extensión reales que produzca cada servicio. No convertirlos previamente a un formato común.

El contenido de esta carpeta está excluido de Git, salvo este README. No forzar su inclusión en commits. Que Git los ignore no los cifra ni impide que otras herramientas o sincronizadores accedan a ellos.

Los archivos pueden contener historial y notas privadas. No incluir credenciales o tokens. No modificar los originales durante el análisis. Si posteriormente se necesitan fixtures públicos, preparar ejemplos mínimos y anonimizados por separado.
